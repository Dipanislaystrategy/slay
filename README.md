# Slay Agency

Official website and digital experience for **Slay The Strategy** — full-service creative & digital production agency based in Bengaluru, Karnataka.

## Pages & Structure

- `/` — Homepage & Showreel
- `/About` — About Slay The Strategy
- `/Services` — Service offerings & capabilities
- `/Work` — Case studies & portfolio
- `/Contact` — Consultation & enquiry form
- `/TnC` — Terms & Conditions
- `/privacy-policy` (`/privacy`) — Privacy Policy

## Getting Started

First, run the development server:

```bash
npm run dev
# or
pnpm dev
# or
yarn dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Build

To create an optimized production build:

```bash
npm run build
```
